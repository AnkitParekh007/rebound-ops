  1. Create a key in your Anthropic account and set a provider-side spend limit. Provider charges may apply to reviews.
  2. Save your session or download a JSON backup before stopping the launcher. Keep your key in the local server environment, not in this browser or Git. To enable AI, stop the launcher and run these commands from the repository root in Bash:
read -rsp 'Anthropic API key: ' ANTHROPIC_API_KEY; echo
export ANTHROPIC_API_KEY
bash scripts/start-demo.sh --ai

The launcher already serves this full recovery interface with the same session. Switching interfaces needs no restart. Save your session or download a JSON backup before restarting to enable AI. Developers running npm run dev separately can set REBOUNDOPS_AI_ENABLED=true in that API terminal. Set REBOUNDOPS_ANTHROPIC_MODEL to override the server’s default model. Environment files are not loaded automatically.

Testing requests metadata for the configured model using the server-side key. It sends no career records and does not generate text. A successful test checks access, not the quality of AI advice. Tests are limited to one per 30 seconds.
