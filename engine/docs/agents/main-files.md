# AGENTS.md reference: Main Files

<!-- Moved verbatim from AGENTS.md to keep the always-loaded context small. AGENTS.md links here with a "MUST read before" trigger. Same authority as AGENTS.md. -->

Paths keep their `AGENTS.md` meaning. System files (scripts, `modes/` except the three user files below, `templates/`, `docs/`, `batch/` scripts) are relative to the engine root, the directory that holds `AGENTS.md`. User-layer paths (`cv.md`, `config/` except the shipped `config/*.example.*` templates, which are engine files, `modes/_profile.md`, `modes/_custom.md`, `modes/_brief.md`, `voice-dna.md`, `data/`, `reports/`, `jds/`, `output/`, `batch/tracker-additions/`, …) resolve under the data root, and the tracker under its own path, exactly as `AGENTS.md` → **Data Contract** defines them: `REBOUND_OPS_ROOT` / `REBOUND_OPS_DATA_DIR` or the `.rebound-ops-data` marker for the root, and `REBOUND_OPS_TRACKER` or `{DATA_ROOT}/data/applications.md` for the tracker, falling back to `{DATA_ROOT}/applications.md` when reading an existing one. Individual files can also be redirected by their own variable, for example `REBOUND_OPS_PROFILE` (profile), `REBOUND_OPS_PORTALS`, `REBOUND_OPS_PIPELINE`, `REBOUND_OPS_SCAN_HISTORY`, `REBOUND_OPS_REPORTS_DIR`, `REBOUND_OPS_FOLLOWUPS` and `REBOUND_OPS_BLACKLIST`. When one is set it wins over the data-root path, so check the environment, or use the script that reads the file, before reading or editing a file at its default path. A nonblank `REBOUND_OPS_PROFILE` resolves a relative value against the working directory; otherwise the profile is `{DATA_ROOT}/config/profile.yml`. In scripts use `path-resolver.mjs` (`getReboundOpsRoot()`, `resolveTrackerPath(root)`, `resolveTrackerPathForWrite(root)`, `getProfilePath()`).

| `sponsor-check.mjs` | UK Skilled Worker sponsor-licence cross-check — answers "does this employer hold a sponsor licence?" against the Home Office "Register of licensed sponsors: workers", which `visa_filter` in `scan.mjs` cannot (it only drops postings that explicitly REFUSE sponsorship).
