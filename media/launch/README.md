## Sequence

| Time | Scene |
| --- | --- |
| 0–4 seconds | Recently laid off? |
| 4–8 seconds | Looking for a career switch or pivot? |
| 8–11 seconds | Your experience. Your next chapter. |
| 11–16 seconds | Evidence review |
| 16–21 seconds | Direction choices |
| 21–26 seconds | A manageable plan |
| 26–34 seconds | Recorded workbench: review the next step and active applications |
| 34–43 seconds | Recorded job search: filter by role and clear the filter |
| 43–56 seconds | Recorded tracker: search applications, switch to Kanban and draft an outcome note |
| 56–60 seconds | Run locally. AI optional. Build with us. |
| 60–67 seconds | ReboundOps project and website links |

The dashboard, job-filter and tracker scenes record interactions with the locally running application using fictional demo records. The outcome note is drafted without submitting or saving it. Evidence, direction and plan scenes use fictional product screenshots. These examples are not customer results. These files are exported videos, not editable Canva timelines. Committing them does not post them to LinkedIn or Product Hunt.
