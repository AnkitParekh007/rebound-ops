# Public-preview kit — ready for owner review, not publication

The ReboundOps repository is public source code, but this kit does **not** authorize a public beta launch, claimed participant outcomes, paid provider use or real-person testimonials.

## 90-second fictional walkthrough

**0–15 seconds — Starting point.** “ReboundOps helps experienced software professionals explore their next career direction after a layoff or career change. We focus on evidence and actions, not an AI-generated hiring score.”

**15–35 seconds — Experience and provenance.** Start the Angular app with its clearly marked fictional sample. Show the evidence list, a short fictional project note and a corrected achievement backed by an exact quotation.

**35–50 seconds — Requirements.** Paste one fictional example of a job requirement. Mark missing proof as unreviewed or a gap; never pretend the match has been independently verified.

**50–70 seconds — Career paths.** Show Return / Shift / Bridge hypotheses, choose one and explain its uncertainty. Point to a seven-day plan within the participant’s time budget.

**70–85 seconds — Progress and privacy.** Complete one mock action, export Markdown, and explain opt-in local storage and deletion. Optional AI requires a separate payload preview, explicit consent and provider setup.

**85–90 seconds — Call to collaborate.** “If you want to review the code or help test a fictional journey, see the repository and its contribution guide.”

Every screen shown publicly must contain **fictional data only**. No real résumés, participant quotes, work identities, keys or income details.

## Release verification checklist

- [ ] Product-owner review of user evaluation findings and limitations
- [ ] Privacy consent language reviewed before enrolling participants
- [ ] 5 discovery interviews and at least 3 complete follow-ups documented privately
- [ ] Browser CI, contract/API tests and accessibility checks green on release commit
- [ ] Manual keyboard, screen reader and current mobile browser tests completed
- [ ] Cross-platform local disk saving/recovery tested; no accidental private file distribution
- [ ] External provider still disabled unless live compatibility, budget and participant privacy are approved
- [ ] No sensitive keys, backups, uploaded résumés or private notes in Git history
- [ ] README and quick-start commands reproducible by an independent contributor
- [ ] License, security and contribution docs reviewed
- [ ] Release notes explicitly distinguish features from limitations
- [ ] Issue triage/bug response owner assigned
- [ ] Approval to publish a release and any public outreach recorded

## Proposed release-note structure

**ReboundOps local preview (candidate, not yet published)**

Included: guided career evidence intake, user-confirmed claims and exact citations, manually reviewed job requirements, three direction hypotheses, time-budgeted recovery plans, check-ins, Markdown export, JSON backup/restore and opt-in local disk saving.

Optional: off-by-default Anthropic review with exact payload preview and explicit consent; **not live-evaluated for real participant use**.

Not included: hosted accounts, automatically verified jobs, salary predictions, job scraping, auto-applications or placement guarantees.

Known limits: local storage is unencrypted; legacy static pilot is preserved; session data is user-controlled; pilot evaluation outcomes are still pending.

## Go/no-go decision

Release only after the owner reviews the blank-to-filled [pilot scorecard](pilot-scorecard.md) and explicitly approves publication. Successful CI alone is not a market validation.
