# Features and limitations

[← Wiki home](Home)

| Area | Available capability | Key boundary |
| --- | --- | --- |
| Career recovery | Guided intake, directions, seven-day time-bounded plan | Suggestions are hypotheses to test |
| Evidence | Achievements, pasted source excerpts, citations, correction and confirmation | User confirmation is not third-party verification |
| Opportunity discovery | Configured public sources and pipeline filtering | Sources may be unavailable or return incomplete results |
| Job evaluation | Requirement/evidence comparison and saved reports | Scores are advisory, not hiring probabilities |
| Application preparation | Editable CV/ CV Studio, draft materials, checklists | AI and browser exports need setup; final review is yours |
| Application tracking | Status, notes and follow-up records | No automatic submission of applications |
| Interview tools | Practice prompts, networking and learning plans | Content must be checked for accuracy |
| Data control | Explicit session saving, JSON/Markdown exports and combined backups | Unencrypted local files; stores are not automatically synchronized |
| Optional AI | Provider-assisted review with consent, where configured | Off by default for recovery; no silent provider calls |

## Scope clarification

The recovery Angular UI and the integrated Node.js workspace are two surfaces with different capabilities. Some tools are available in one but not identically in the other.

Current release scope is **local developer preview for Linux/macOS**. Native Windows remains experimental. Hosted account management, a broad public beta, and native desktop apps should **not** be presented as released capabilities.

Follow the [screenshots](https://rebound-ops.org/screenshots/) and [main README](https://github.com/AnkitParekh007/rebound-ops/blob/main/README.md) for a hands-on overview. Future ideas belong in [GitHub Discussions](https://github.com/AnkitParekh007/rebound-ops/discussions), while reproducible bugs belong in [Issues](https://github.com/AnkitParekh007/rebound-ops/issues).
